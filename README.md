# 🤖 AI 資訊查核助手 LINE Bot

## 1. 專案概述

本專案為部署於 **Google Apps Script (GAS)** 的全方位 **AI 資訊查核與民生便民助手**，專為 LINE 個人與群組設計。具備四大核心支柱：
1. **「數位內容鑑識與謠言闢謠」**：直連 Cofacts 闢謠庫與二段式權威爬蟲，秒辨真偽。
2. **「影片精華整理」**：抓取真實 oEmbed 標題，萃取章節大綱與受眾分析。
3. **「詐騙網址與釣魚鑑識」**：三層防護（特徵評分 + 即時內文抓取 + AI 深度鑑識）。
4. **「台灣 6 大官方開放資料 API 矩陣」**：
   - **🚗 國道即時路況與車速**：交通部 TDX VD 車輛偵測時速與事故通報（支援動態 ETA 抵達時間計算）。
   - **🅿️ 智慧路外停車**：交通部 TDX 公有路外停車場即時剩餘車位、燈號狀態與 Google 地圖導航。
   - **🌤️ 今明 36 小時多日氣象**：TDX / 中央氣象署 (CWA) 官方預報 + 全球毫秒級備援（完整提供今日現況、明日白天預報與降雨機率 %）。
   - **⛽ 台灣中油即時油價**：中油官方最新汽柴油牌價與生效日期。
   - **🧾 財政部統一發票**：ETAX 官方即時開獎獎號解析。
   - **🏥 健保署急診看板**：衛福部重度急救責任醫院即時滿床與就醫等待人數。

## 3. 核心技術特色

### 🚀 智慧型標題解析 (oEmbed Integration)

為了解決 AI 對於純 YouTube 網址可能產生的「幻覺」或「亂猜」問題，本程式會先透過官方 oEmbed API 抓取影片的「真實標題」與「頻道名稱」傳遞給 AI，確保分析的起點絕對準確。

### 🛡️ 多模型自動降級備援機制 (Auto-Fallback)

為應對大型模型在高負載時可能出現的 503 或 429 錯誤，系統建立了一套 Google 官方最新、新用戶 100% 支援的四階多層防護網，按效能與延遲順序自動切換模型：

1. **Gemini 3 Flash Preview (`gemini-3-flash-preview`)** (Tier 1 主力首選：2026 全新 3 系列架構，推論、多模態與鑑識能力最強，新帳號原生支援)
2. **Gemini 3.1 Flash-Lite-Preview (`gemini-3.1-flash-lite-preview`)** (Tier 2 極速防線：極低延遲、高頻率配額，確保 LINE Webhook 絕不逾時)
3. **Gemini 2.5 Flash (`gemini-2.5-flash`)** (Tier 3 穩定備援：官方經典穩定 Flash 版)
4. **Gemini 3.1 Pro Preview (`gemini-3.1-pro-preview`)** (Tier 4 旗艦備援：**Google 官方指定取代 2.5-pro 之最新深度旗艦**，專責高難度複雜鑑識)


### 🌐 免帳號、免綁卡之深度事實查核 (Deep Web Fact-Checking)

系統已內建免申請帳號、免綁信用卡的完整查核管線：

1. **Cofacts（真的假的）闢謠庫直連**：以 GraphQL 即時查詢台灣開源查核資料庫，命中時直接取得查核員之闢謠依據與反駁出處。
2. **DuckDuckGo 多方來源擴展檢索**：自動取得 8 筆即時搜尋結果，並對事實查核中心 (`tfc-taiwan.org.tw`)、MyGoPen (`mygopen.com`)、政府機關 (`.gov.tw`) 等權威網域進行加權排序。
3. **二段式深度內文爬取 (Deep Crawl)**：自動點入權威性最高的來源網頁，抓取前 1,500 字乾淨正文，讓 AI 不僅看摘要，更能比對完整脈絡。

> 💡 **全免成本**：完全不需使用付費的 Google Search Grounding，保持 `ENABLE_GROUNDING = false` 即可享有完整即時查核能力！

### 🔍 詐騙網址偵測：白名單放行 + 靜態特徵 + 網頁鑑識 + AI 四層防護

系統採用完整的「官方信任白名單」搭配「GAS 相容正則解析」、「網頁關鍵特徵鑑識」最後由「AI 直球結論」的防護管線：

1. **官方信任白名單庫 (Trusted Whitelist)**：
   - 自動識別並放行政府與學校 (`*.gov.tw`, `*.edu.tw`)、主流電商官方短網址（如蝦皮 `shopee.tw`, `shp.ee`, `tw.shp.ee`、`momo.dm`、`pchome.com.tw`）及合法電子禮券平台（統一超商 i禮讚 `ibongift.com`、`edenred.tw` 宜睿智慧等），直接評定為安全，免受誤判困擾。
2. **GAS 環境專屬 URL 正則解析器 (`parseUrlSafe`)**：
   - 解決 Google Apps Script 缺少標準 `new URL()` 導致的 `ReferenceError` 假攔截問題，精準提取網域與參數。
3. **靜態特徵與釣魚表單深度掃描**：
   - 掃描山寨網域（如 `shopeee`）、高風險 TLD (`.shop`, `.top`, `.xyz`)、隨機亂碼主網域。
   - 自動探測頁面原始碼中是否含有索取「信用卡號、CVV、網銀密碼、動態簡訊碼」等高危欄位，或是否整合 OPENPOINT 等「官方 App 深度跳轉（Deep Link）」。
4. **反爬保護容錯與 AI 研判**：
   - 若遇到電商 App 反爬保護（HTTP 403），自動傳遞客觀狀態，避免 AI 因無法讀取內文而誤判為釣魚網站。

| 檢查項目 | 偵測特徵 | 評定權重 |
| :--- | :--- | :---: |
| **官方認證網域** | 蝦皮官方 (`tw.shp.ee`)、統一超商 i禮讚 (`ibongift.com`) 等白名單 | **直接 0 分安全** |
| **高風險 TLD** | `.shop`, `.top`, `.xyz`, `.vip`, `.site`, `.cc`, `.fun`, `.online`, `.buzz` | +40 分 |
| **詐騙參數組合** | `m=order`, `tpl=detail`, `id=`, `lang=zh-tw`（2 個以上） | +50 分 |
| **亂碼網域** | 主網域長度 >8 且含過多數字 or 缺少母音 | +30 分 |
| **山寨品牌比對** | 拼寫相近（如 `shopeee`, `tw-momo`, `m0m0`） | +60 分 |

> 💡 **評分邏輯**：靜態分數 **70 分以上**判定為高度風險。若命中官方白名單則評為 0 分安全。該特徵會一併提供給 Gemini AI 產生極簡結論。

### 🏢 台灣 6 大官方開放資料 API 矩陣與動態注入
在 [`Code_Interactions.gs`](./Code_Interactions.gs) 中，系統直接介接台灣官方與權威資料庫，不經由第三方二手二手轉載：
1. **交通部 TDX 國道車流與事故**：即時抓取時速低於 70km/h 瓶頸路段與即時通報，並支援動態 ETA 推算。
2. **交通部 TDX 智慧路外停車**：取得全台公有停車場即時剩餘格位與客滿燈號，自動生成 Google 地圖一鍵導航連結。
3. **中央氣象署 (CWA) 今明 36 小時預報**：提供今日現況、今晚明晨、明日白天與後天之完整預報與降雨機率 %。
4. **台灣中油牌價**：自動解析官方最新牌價，條列 98/95/92/柴油參考零售價格。
5. **衛福部健保署重度急診看板**：查詢各責任醫院看診、住院、ICU 等待人數與滿床預警。
6. **財政部 ETAX 統一發票**：官方 XML 即時開獎獎號解析。

### 🛡️ 高強健反幻覺與雙軌回答機制 (Truthful & Hallucination-Free)
為避免大語言模型捏造即時數據，系統內建嚴格反幻覺 Prompt 規範：
- **無即時公有感測數據時，絕不憑空臆測**：例如查詢民營商場內部車位時，若非公有連線即時資料，AI 誠實告知「依現場看板為準」，並提供正確費率與周邊公有停車場。
- **時空座標精確注入**：系統在每次發問時自動注入台灣標準時間（GMT+8），避免時間軸混淆。
- **LINE 專屬 Markdown 清洗防護**：回傳前強制執行 `sanitizeForLine`，徹底清洗 `#`, `**`, `---` 語法，排版維持最舒服的行動端屏效比。
- **全系統 CacheService 高速快取**：白名單、TDX Token、路況、天氣、油價、發票、急診全覆蓋，降低延遲並防止 Webhook 逾時。

### 🚫 封閉式白名單安全性

- **群組鎖定**：僅限列於 `ALLOWED_GROUP_IDS` 白名單中的專屬群組提供服務。
- **私訊防護**：對私訊者提供客氣的「家用私人專用」拒絕訊息，減少不必要的 API 消耗。
- **終端指令**：提供隱藏指令 `/get_group_id` 或 `/get_id` 方便管理員快速獲取群組或個人代碼。

## 4. AI 分析準則與極簡排版規範 (System Instruction)

本專案全面採取 **「極致精簡、直球對決」** 規範，專為 LINE 行動端優化，**不使用 Markdown**，徹底杜絕冗長條列套話：

### 📱 訊息輸出統一三層結構
```
[燈號/圖示] 最終結論（1~3 句話直球對決，切中核心）

🔗 求證連結：（僅在事實查核或檢索到權威出處時附上，無則自動省略）
▫️ 出處標題：網址連結

🤖 模型：gemini-3-flash-preview
```

### 🔍 各情境呈現標準
* **⚖️ 資訊查核模式**：
  * **燈號**：🔴 錯誤謠言 / 🟡 部分不實(存疑) / 🟢 屬實訊息
  * **內容**：1~2 句話直球指出事實真相與科學/醫學闢謠依據，文末附上求證連結。
* **🔍 詐騙網址偵測模式**：
  * **燈號**：🟢 官方安全連結 / 🟡 中風險需留意 / 🔴 高風險詐騙
  * **內容**：說明是否為官方正規網址/跳轉，是否有索取信用卡與帳密風險，告知使用者該怎麼做。
* **📝 影片整理模式**：
  * **圖示**：📝 重點精華
  * **內容**：2~3 句話提煉全片最核心論點與收穫。
* **💡 生活與即時問答模式**：
  * **圖示**：💡 核心結論
  * **內容**：直球給出核心答案（發票直接列獎號、國道路況直接給車程與時速）。
* **🤖 判別回應模型標籤**：
  * 無論切換至哪一個備援模型，訊息底部固定標註 `🤖 模型：<model-name>`。

## 5. AI 生成參數說明 (Generation Config)

為了確保事實查核的品質，本專案對 AI 的生成參數進行了優化設定：

| 參數 | 設定值 | 為什麼要這樣設定？ |
| :--- | :--- | :--- |
| **Temperature** | `0.3` | **確保穩定性**：設定較低的值可降低 AI 隨機發揮的機率，確保對於同一個連結，AI 每次都能產出嚴謹、一致且基於事實的查證結果。 |
| **Max Output Tokens** | `2000` | **保留思考空間**：最新的 Gemini 2.x 模型具備「深度思考」機制。調高上限並非為了輸出長篇大論（我們會用指令控在 250 字內），而是**確保 AI 的背景推導過程不會因為額度不足而被強制截斷**導致當機。 |
| **Google Search** | `ENABLE_GROUNDING` 旗標控制 | **Free Tier（false）**：完全不使用，$0 元。**付費模式（true）**：動態觸發，超出免費配額後 $14/1000 次。 |

## 8. 部署與設定教學

### 第一步：基礎環境準備

1. 前往 [LINE Developers Messaging API](https://developers.line.biz/en/services/messaging-api/) 建立 Channel（點擊「Start now」登入建立），取得 `Channel Access Token`（詳見 [詳細設定指南](./deployment_guide.md)）。
2. 前往 [Google AI Studio](https://aistudio.google.com/) 取得 `Gemini API Key`（詳見 [詳細設定指南](./deployment_guide.md)）。
3. *(選填，推薦)* 前往 [交通部 TDX 平臺](https://tdx.transportdata.tw/) 免費申請會員，取得 `Client ID` 與 `Client Secret`（**一組金鑰搞定國道即時車速與全台路外停車位**）。

### 第二步：GAS 部署與設定「指令碼屬性」 (關鍵安全設定)

為了確保金鑰安全，本專案建議將 API Key 存放在 GAS 的「指令碼屬性」中，而非直接寫在程式碼裡。系統已內建 `.trim()` 安全防護：

1. 在 GAS 編輯器左側選單點選 **「專案設定」** (齒輪圖示 ⚙️)。
2. 捲動至最下方找到 **「指令碼屬性」** 區塊。
3. 點選 **「編輯指令碼屬性」** ➔ **「新增指令碼屬性」**：
   - `LINE_ACCESS_TOKEN`：貼入您的 LINE Token。
   - `GEMINI_API_KEY`：貼入您的 Gemini API Key。
   - `ALLOWED_GROUP_IDS` *(選填)*：貼入允許的 LINE 群組 ID (多個請用逗號 `,` 分隔；可填 `*` 開放所有群組)。
   - `ALLOWED_USER_IDS` *(選填)*：貼入允許一對一私訊的 LINE 使用者 ID (多個請用逗號 `,` 分隔；可填 `*` 開放所有人私訊)。不與群組 ID 混用。
   - `TDX_CLIENT_ID` *(推薦)*：貼入 TDX Client ID。
   - `TDX_CLIENT_SECRET` *(推薦)*：貼入 TDX Client Secret。
   - `CWA_API_KEY` *(選填)*：中央氣象署授權碼（若無則自動啟用全球多日預報備援）。
   - `SPREADSHEET_ID` *(選填)*：若使用 `Code_Interactions.gs` 且希望透過 Google Sheet 管理白名單，請填入試算表 ID。
4. 點選 **「儲存指令碼屬性」**。
5. 點選 **「部署」➔「管理部署」➔「編輯」➔ 版本選「新版本」** 進行發布。
6. 複製產出的 **Web App URL**，回到 LINE Developers 貼入 **Webhook URL** 並開啟 **Use webhook** 開關。
