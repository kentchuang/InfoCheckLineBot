# 🤖 AI 資訊查核助手 LINE Bot

## 1. 專案概述

本專案為部署於 **Google Apps Script (GAS)** 的高效能 **AI 資訊查核助手**，專為 LINE 群組設計。具備三大核心功能：**「數位內容鑑識」**、**「影片精華整理」**與全新加入的 **「詐騙網址偵測」**。能精準判別影片真偽、識別 AI 生成內容，並能即時鑑別可疑詐騙連結，防止群組成員受到釣魚攻擊。

---

## 2. 使用說明 (Keywords)

本機器人採用 **「主動 @TAG 聯網問答」** 與 **「被動關鍵字守護」** 雙軌機制，平時在群組保持靜默，不打擾日常閒聊：

| 觸發方式 | 常用格式 / 關鍵字 | 行為與功能 |
| :--- | :--- | :--- |
| **🤖 @AI / @bot 主動喚醒** | `@AI`, `@ai`, `@Ai`, `@Bot`, `@bot` 任一開頭<br>（如：`@ai 今天台北天氣如何`、`@Bot 推薦拉麵`） | **自動問題整理 + DuckDuckGo 即時檢索**：自動上網搜尋最新資料（氣象、時事、各類知識問答），並附上資料來源連結。<br>*(精準過濾：日常輸入 Email 如 `abc@gmail.com` 絕不誤觸)* |
| **⚖️ 資訊查核** | `資訊查核`, `查核`, `事實查核`, `闢謠`, `真的假的` | 進行真偽鑑定、AI 參與度分析、Cofacts 比對與資料來源核實出處。 |
| **🎬 影片整理** | `影片整理`, `整理`, `影片大綱`, `大綱`, `摘要` | 抓取 YouTube oEmbed 資訊並生成核心精華大綱。 |
| **🔍 詐騙網址偵測** | `詐騙`, `釣魚`, `可疑`, `偵測`, `安全嗎`, `網址查核` | 静態風險評分結合即時網頁抓取與 AI 深度鑑識，判定是否為釣魚連結。 |
| **📋 指令查詢** | `指令查詢`, `幫助`, `help`, `/help` | 顯示目前的指令表與使用範例。 |

> 💡 **小撇步**：想查今天天氣、即時新聞或生活問題時，只要在訊息中輸入 **`@AI`**、**`@ai`**、**`@Ai`**、**`@Bot`** 或 **`@bot`** 即可！
> 💡 **小撇步**：一般聊天沒提到機器人或關鍵字時，機器人會保持靜默，不擾民、不洗版。

## 3. 核心技術特色

### 🚀 智慧型標題解析 (oEmbed Integration)

為了解決 AI 對於純 YouTube 網址可能產生的「幻覺」或「亂猜」問題，本程式會先透過官方 oEmbed API 抓取影片的「真實標題」與「頻道名稱」傳遞給 AI，確保分析的起點絕對準確。

### 🛡️ 多模型自動降級備援機制 (Auto-Fallback)

為應對大型模型在高負載時可能出現的 503 或 429 錯誤，系統建立了一套官方正式支援的五階多層防護網，按效能與延遲順序自動切換模型：

1. **Gemini 3.8 Flash** (Tier 1 尖端旗艦首選：2026 最新主力，推論、多模態與鑑識能力最強)
2. **Gemini 2.5 Flash** (Tier 2 穩定基石：官方正式長期支援版，配額最充足、最少過載，Free Tier 最佳保底)
3. **Gemini 3 Flash Preview** (Tier 3 新世代預覽：3 系列標準 Flash，平衡速度與推理深度)
4. **Gemini 3.1 Flash-Lite-Preview** (Tier 4 極速防線：極低延遲、高頻率配額，確保 LINE Webhook 絕不逾時)
5. **Gemini 2.5 Pro** (Tier 5 備援旗艦：高難度複雜鑑識保底備用)

### 🌐 免帳號、免綁卡之深度事實查核 (Deep Web Fact-Checking)

系統已內建免申請帳號、免綁信用卡的完整查核管線：

1. **Cofacts（真的假的）闢謠庫直連**：以 GraphQL 即時查詢台灣開源查核資料庫，命中時直接取得查核員之闢謠依據與反駁出處。
2. **DuckDuckGo 多方來源擴展檢索**：自動取得 8 筆即時搜尋結果，並對事實查核中心 (`tfc-taiwan.org.tw`)、MyGoPen (`mygopen.com`)、政府機關 (`.gov.tw`) 等權威網域進行加權排序。
3. **二段式深度內文爬取 (Deep Crawl)**：自動點入權威性最高的來源網頁，抓取前 1,500 字乾淨正文，讓 AI 不僅看摘要，更能比對完整脈絡。

> 💡 **全免成本**：完全不需使用付費的 Google Search Grounding，保持 `ENABLE_GROUNDING = false` 即可享有完整即時查核能力！

### 🔍 詐騙網址偵測：靜態 + 抓取 + AI 三層防護

系統採用「靜態規則評分」搭配「即時網頁抓取」最後由「AI 深度研判」的完整架構：

| 風險檢查項目 | 偵測特徵 | 權重 (+ 分) |
| :--- | :--- | :---: |
| **高風險 TLD** | `.shop`, `.top`, `.xyz`, `.vip`, `.site`, `.cc`, `.fun`, `.online`, `.buzz` | +40 |
| **詐騙參數組合** | `m=order`, `tpl=detail`, `id=`, `lang=zh-tw`（2 個以上） | +50 |
| **亂碼網域** | 主網域長度 >8 且含過多數字 or 隨機字母 | +30 |
| **山寨品牌比對** | 拼寫相近（如 `shopeee`, `tw-momo`, `m0m0`） | +60 |

> 🚀 **進階防護**：除了網址特徵，系統會利用 GAS 內建 `UrlFetchApp` 即時抓取網頁標題與內容，讓 AI 能直接識別釣魚頁面的實際意圖，大幅提升偵測率。

> 💡 **評分邏輯**：靜態分數 **70 分以上**判定為高度風險。該分數會一併傳遞給 Gemini AI 作為判斷參考。

### 🚫 封閉式白名單安全性

- **群組鎖定**：僅限列於 `ALLOWED_GROUP_IDS` 白名單中的專屬群組提供服務。
- **私訊防護**：對私訊者提供客氣的「家用私人專用」拒絕訊息，減少不必要的 API 消耗。
- **終端指令**：提供隱藏指令 `/get_group_id` 方便管理員快速獲取群組代碼。

## 4. AI 分析準則 (System Instruction)

本機器人支援雙模式運作，專為 LINE 行動端優化，**不使用 Markdown**：

### ⚖️ 資訊查核模式

1. **[燈號] 核心摘要**：使用 🔴🟢🟡 燈號秒懂影片真偽。
2. **🤖 AI 鑑定**：識別標題黨、AI 腳本與內容農場跡象。
3. **⚖️ 真實性評估**：識別事實錯誤或邏輯謬誤。

### 📝 影片整理模式

1. **📌 核心大綱**：將內容分為 3-5 個主要章節或主題。
2. **💡 適合誰看**：分析目標受眾與建議。
3. **🚩 快速總結**：用一句話提煉影片精華。

### 🔍 詐騙網址偵測模式

1. **🔍 深度鑑識分析**：檢查是否品牌模仿，掃描內文是否包含「限時搶購」、「帳號異常」等詐騙語義，並比對圖文一致性。
2. **🛡️ 安全評級**：整合靜態網域風險評分與 AI 深度判斷，給出 🔴/🟡/🟢 明確評級。
3. **🚫 專家建議**：給予使用者明確的防禦動作指示（如：切勿輸入個資、立即關閉）。

| 參數 | 設定值 | 為什麼要這樣設定？ |
| :--- | :--- | :--- |
| **Temperature** | `0.3` | **確保穩定性**：設定較低的值可降低 AI 隨機發揮的機率，確保對於同一個連結，AI 每次都能產出嚴謹、一致且基於事實的查證結果。 |
| **Max Output Tokens** | `2000` | **保留思考空間**：最新的 Gemini 2.x 模型具備「深度思考」機制。調高上限並非為了輸出長篇大論（我們會用指令控在 250 字內），而是**確保 AI 的背景推導過程不會因為額度不足而被強制截斷**導致當機。 |
| **Google Search** | `ENABLE_GROUNDING` 旗標控制 | **Free Tier（false）**：完全不使用，$0 元。**付費模式（true）**：動態觸發，超出免費配額後 $14/1000 次。 |

## 8. 部署與設定教學

### 第一步：基礎環境準備

1. 前往 [LINE Developers](https://developers.line.biz/) 建立 Channel，取得 `Channel Access Token`（詳見 [詳細設定指南](./deployment_guide.md)）。
2. 前往 [Google AI Studio](https://aistudio.google.com/) 取得 `Gemini API Key`（詳見 [詳細設定指南](./deployment_guide.md)）。


### 第二步：GAS 部署與設定「指令碼屬性」 (關鍵安全設定)

為了確保金鑰安全，本專案建議將 API Key 存放在 GAS 的「指令碼屬性」中，而非直接寫在程式碼裡。

1. 在 GAS 編輯器左側選單點選 **「專案設定」** (齒輪圖示 ⚙️)。
2. 捲動至最下方找到 **「指令碼屬性」** 區塊。
3. 點選 **「編輯指令碼屬性」** ➔ **「新增指令碼屬性」**：
   - 屬性 (Property)：`LINE_ACCESS_TOKEN` / 值 (Value)：貼入您的 LINE Token。
   - 屬性 (Property)：`GEMINI_API_KEY` / 值 (Value)：貼入您的 Gemini API Key。
   - 屬性 (Property)：`ALLOWED_GROUP_IDS` / 值 (Value)：貼入允許的群組 ID (多個請用逗號 `,` 分隔；若使用 `Code_Interactions.gs` 且想開通個人私訊，亦可將個人 User ID 填於此)。
   - *(選填，僅限進階試算表控管)* `SPREADSHEET_ID`：若使用 `Code_Interactions.gs` 且希望透過 Google Sheet 管理白名單，請填入試算表 ID。
4. 點選 **「儲存指令碼屬性」**。
5. 點選 **「部署」➔「管理部署」➔「新版本」** 進行發布。
   - 執行身分：**我**
   - 誰可以存取：**所有人 (Anyone)**
6. 複製產出的 **Web App URL**，回到 LINE Developers 貼入 **Webhook URL** 並開啟 **Use webhook** 開關。

### 第三步：啟用群組白名單

1. 將機器人加入您要使用的群組。
2. 在群組輸入指令：`/get_group_id`。
3. 取得 `C` 開頭的編碼後，前往 GAS **「專案設定」** ➔ **「指令碼屬性」**，將其填入 `ALLOWED_GROUP_IDS` 屬性中。
4. 若已有其他群組，請使用半形逗號 `,` 分隔即可，不需重新部署程式碼。
